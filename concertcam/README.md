# 콘서트캠 (ConcertCam)

콘서트장 전용 안드로이드 카메라 앱. 갤럭시 S25 울트라 기준으로 만들었다(Android 12 이상에서 설치 가능).

## 무엇을 하는가

| 문제 | 앱이 하는 일 |
| --- | --- |
| 고배율에서 얼굴이 뭉개짐 | 한 번 누르면 여러 장(기본 6장)을 찍어, 가장 덜 흔들린 장을 기준으로 나머지를 정합·합성한다. 기기 내장 노이즈 제거는 약하게 걸고 노이즈는 합성으로 줄인다. 많이 잘라 낸 고배율 사진은 2배 격자에 쌓아 해상도를 보강한다. |
| 조명 때문에 얼굴이 하얗게 날아감 | 추적 중인 얼굴에 측광을 맞추고, 얼굴이 날아가면 노출을 자동으로 낮춘다. 기본 노출 보정 -0.7 EV. |
| 움직임이 번짐 | 설정에서 셔터 속도를 고정(1/250 등)하면 ISO를 앱이 자동으로 맞춘다. |
| 인물 자동 추적 | 얼굴 인식으로 대상을 잡고, 얼굴이 안 보이는 순간은 직전 위치 주변의 닮은 영역을 따라간다. 화면을 누르면 그 대상으로 고정, 길게 누르면 자동(가장 큰 얼굴)으로 돌아간다. 초점·노출이 대상을 따라가고, 5배 초과 줌에서는 화면도 대상을 가운데로 따라간다(오토 프레이밍). |
| LED 전광판의 도트·줄무늬 | "LED 스크린" 모드에서 촬영하면 주파수 영역에서 격자·모아레 성분만 골라 깎는다(약/중/강). 초점을 살짝 빼서 찍는 옵션도 있다. |

조작: 화면 탭 = 대상 고정, 길게 누르기 = 해제, 두 손가락 = 줌, 음량 버튼 = 촬영.
사진은 `Pictures/ConcertCam`에 저장된다.

## 구조

- `imaging/` — 안드로이드와 무관한 순수 Kotlin 이미지 처리(모아레 제거, 프레임 정합, 합성, 샤픈, 조각 추적). PC에서 단위 테스트한다.
- `app/` — CameraX 기반 카메라 앱. 얼굴 인식은 ML Kit(모델 내장, 인터넷 불필요).

## 빌드

```bash
./gradlew :imaging:test
```

```bash
./gradlew :app:assembleRelease
```

결과물: `app/build/outputs/apk/release/app-release.apk`

서명 키는 저장소에 올리지 않는다. 프로젝트 루트에 `keystore.properties`(storeFile, storePassword, keyAlias, keyPassword)와
키 파일을 두면 그 키로 서명하고, 없으면 디버그 키로 서명한다. **같은 키로 서명해야 기존 설치본 위에 업데이트로 깔린다.**

실제 사진으로 모아레 제거만 돌려 보기:

```bash
./gradlew :imaging:demo --args="descreen 입력.jpg 출력.png 2"
```

## 검증 상태

- 이미지 처리(`imaging`)는 단위 테스트와 실제 전광판 사진으로 확인했다.
- 카메라 동작(줌 렌즈 전환, 셔터 고정, 초점 빼기, 추적 화면 좌표)은 실제 기기에서 확인하지 못했다.
