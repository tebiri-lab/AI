# 콘서트 인물 사진 보정 — 인수인계 (포토샵 로컬 세션용)

> 새 세션은 이 문서를 먼저 읽고 이어서 작업한다. 대화는 **항상 한국어**로 한다.

## 0. 작업 환경
- 저장소: `tebiri-lab/AI`, 브랜치: `claude/jolly-feynman-2qsurs`
- PC에서 받기:
  ```bash
  git fetch origin claude/jolly-feynman-2qsurs
  ```
  ```bash
  git checkout claude/jolly-feynman-2qsurs
  ```
- 세션은 데스크톱 앱의 **로컬 세션**으로 연다 (`claude remote-control`이나 클라우드 세션은 쓰지 않는다. 원격 왕복 때문에 느리고, 클라우드에서는 PC의 포토샵에 접근할 수 없다).
- 포토샵은 메뉴를 하나씩 클릭하지 말고 **ExtendScript(.jsx) 스크립트로 실행**한다 (화면 조작은 매우 느림).

## 1. 목표
폰으로 찍은 콘서트 사진(베이스 연주자)에 LUT를 적용한 상태에서
1. 인물을 선명하게 보정하고
2. 홈마(DSLR 직찍) 스타일 버전을 만든다.

**원본 파일부터 처음부터** 작업한다. 이전 결과물은 비교용으로만 쓴다.

## 2. 절대 조건: AI 생성 금지 (비생성 기법만)
| 금지 (AI 기반) | 대신 쓸 기능 (비AI) |
|---|---|
| 피사체 선택, 오브젝트 선택 | 펜 툴, 채널 마스크, `homma_mask.png` |
| 선택 및 마스크의 '오브젝트 인식' 모드 | '색상 인식' 모드 + 가장자리 다듬기 브러시 |
| 생성형 채우기, 뉴럴 필터 | 사용 안 함 |
| Camera Raw의 AI 노이즈 제거, AI 마스크, 렌즈 흐림 | 필터 > 노이즈 > 노이즈 감소, Camera Raw 수동 노이즈 슬라이더 |
| 슈퍼 해상도 (2배 확대) | 이미지 크기 변경의 보간 방식 (생성 아님, 디테일은 늘지 않음) |
| — | 필터 > 흐림 효과 > 렌즈 흐림 (마스크를 깊이 맵으로), 고급 선명 효과 '렌즈 흐림 제거', 주파수 분리, 노이즈 추가 |

판단이 애매한 기능이 있으면 쓰기 전에 사용자에게 먼저 묻는다.

## 3. 파일 (`retouch/`)
| 파일 | 내용 |
|---|---|
| `original.jpg` | **기준 원본** (폰 촬영 JPG, 1125×2000, SNS·메신저 재압축 가능성 있음) |
| `bass_stage_natural.cube` | LUT (33³, R 채널이 가장 빠르게 변하는 표준 .cube 순서) |
| `enhance.py` | Python 1차 보정 (참고용) |
| `homma.py` | Python 홈마 스타일 (참고용) |
| `enhanced*.jpg/tif/png` | 1차 보정 결과 (비교용) |
| `homma_16bit.tif/png`, `homma_preview.jpg` | 홈마 스타일 결과 (비교용, 4:5, 1070×1338) |
| `homma_mask.png` | GrabCut + 가이디드 필터로 만든 인물 마스크 (원본 해상도, 크롭 전). 베이스 넥·헤드·오른팔 포함 |
| `enhanced_mask.png` | 1차 보정용 대략적인 인물 영역 마스크 (경계를 크게 흐림) |

## 4. 포토샵 작업 순서
1. `original.jpg`를 열고 **이미지 > 모드 > 16비트**로 변환한다.
2. **노이즈 감소 (샤프닝보다 먼저)**: 색 노이즈는 강하게, 광도 노이즈는 약하게 줄인다.
3. **LUT**: 색상 검색(Color Lookup) 조정 레이어로 `bass_stage_natural.cube`를 적용한다.
4. **캡처 샤프닝**: 고급 선명 효과의 '렌즈 흐림 제거' 모드(디컨볼루션)를 광도 기준으로, 반경 약 1px로 약하게 적용한다.
5. **인물 마스크**
   - `homma_mask.png`를 불러와 시작점으로 쓰거나, 펜 툴과 '색상 인식' 모드로 다시 만든다.
   - 머리카락 경계는 가장자리 다듬기 브러시로 정리한다.
6. **인물만 샤프닝**: 언샤프 마스크나 하이패스를 쓰되, 한계값을 둬서 피부 노이즈가 올라오지 않게 한다. 배경은 약 25% 강도로만 넣는다.
7. **홈마 스타일**
   - 배경 렌즈 흐림: 마스크를 깊이 맵으로 쓴다. 이전 결과물은 반경 16px 원형 커널이었다.
   - 얼굴 닷지 앤 번: 얼굴은 살짝 밝게, 눈가는 국소 대비를 올린다.
   - 4:5 크롭: 상반신과 베이스 헤드가 들어가게 한다. 이전 결과물은 원본 기준 x 40~1110, y 110~1448 범위였다.
   - 비네팅: 얼굴 중심으로 은은하게 넣는다.
   - 필름 그레인: 노이즈 추가(가우시안, 단색), 약하게 넣는다.
8. **저장**: `retouch/`에 PSD(레이어 유지), 16비트 TIFF, 16비트 PNG로 저장한다.

## 5. 이전 결과에서 개선할 점
- **머리카락 경계가 칼같이 잘린 느낌**: 배경 전체를 같은 양으로 흐렸기 때문이다. 이번 작업의 최우선 개선 대상이다.
- **머리 주변 LED 격자무늬(모아레) 강조**: 1차 보정에서 샤프닝 영역이 머리 바깥까지 걸쳐서 생겼다. 홈마 버전에서는 배경 블러로 사라졌다.
- **조정 가능한 값**: 블러 강도, 그레인 양, 크롭 범위는 사용자 피드백에 따라 바꾼다.

## 6. 사용자에게 알려 둔 한계
- 비생성 보정으로는 원본에 없는 디테일(폰 자동 처리로 뭉개진 머리카락·피부)을 되살릴 수 없다. 확대는 보간일 뿐 화질 향상이 아니다.
- 홈마 사진과의 차이는 대부분 촬영 장비(풀프레임 센서, 망원 렌즈, RAW 촬영)에서 온다. 보정으로는 색감, 분리감, 질감까지만 흉내 낼 수 있다.

## 7. 사용자 작업 원칙 (요약)
- 실행 요청(만들어줘, 정리해줘 등)은 바로 실행한다.
- 작업이나 논증을 부정하는 반례를 발견하면 반드시 알리고 의견을 묻는다.
- 정의와 검증은 지금 주어진 맥락 안에서만 한다.
