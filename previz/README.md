# Video Skill

AI 영상 작업을 돕는 브라우저 도구 모음입니다. 프리비즈, 구도 실험실, 프롬프트 게이지 탭이 있습니다.

## 프리비즈 (three.js)

샷 설명(텍스트)이나 샷 빌더로 카메라 무빙을 자동 생성하고, 애니매틱·glTF·AI 영상 프롬프트로 내보내는 브라우저용 프리비즈 도구입니다.

## 실행

빌드가 필요 없습니다. three.js는 `vendor/`에 포함되어 있어 오프라인에서도 동작합니다. ES 모듈을 쓰기 때문에 로컬 서버로 열어야 합니다.

```bash
cd previz
python3 -m http.server 8000
# http://localhost:8000
```

GitHub Pages 같은 정적 호스팅에 `previz/` 폴더를 그대로 올려도 됩니다.

## 기능

- **텍스트 → 샷 생성**: 한 줄에 한 샷씩 씁니다. 예: `배우A 클로즈업 로우앵글 천천히 달리인 85mm 4초 | 비 오는 골목에서 뒤돌아본다`
  - `|` 뒤에 쓴 내용은 액션 설명으로 들어갑니다.
  - 인식하는 항목: 샷 사이즈(ECU~EWS), 앵글(로우/하이/탑뷰/웜즈아이), 방향(정면/3/4/측면/뒷모습/오버숄더), 무브(달리 인/아웃, 트럭, 크레인, 오빗·360, 트래킹, 팬, 틸트, 휩팬, 달리줌, 드론), 속도, 핸드헬드, 더치, `NNmm`, `N초`, 씬 오브젝트 이름
- **샷 빌더**: 피사체, 사이즈, 앵글, 렌즈, 무브를 드롭다운으로 골라 생성합니다. 거리는 렌즈 초점거리, 센서 크기, 화면비로 계산해서 실제 프레이밍에 맞춥니다.
- **디렉터 뷰와 샷 카메라 뷰**: 카메라, 타깃, 오브젝트를 기즈모로 움직이면 현재 시간에 키가 생깁니다(자동 키). 타임라인에서 키를 드래그해 타이밍을 바꿀 수 있습니다.
- **XYZ 게이지**: 오브젝트 위치·회전과 카메라 위치·타깃을 슬라이더와 숫자 칸으로 조절합니다. 기즈모 색과 같은 색(X 빨강, Y 초록, Z 파랑)을 씁니다.
- **모든 키에 적용**: 카메라 키 하나를 고친 뒤 버튼을 누르면, 그 키가 바뀐 만큼(위치·타깃·렌즈·롤)을 나머지 키에도 똑같이 더합니다.
- **고개 조절**: 인물을 선택하면 고개 게이지(좌우·위아래·기울기, 인물 기준 °)가 나옵니다. 포즈의 고개 각도 위에 더해지고, 이 샷에 키가 있으면 키로 들어가 샷 안에서 고개를 돌리는 동작을 만들 수 있습니다. `정면으로` 버튼으로 되돌립니다.
- **타깃 고정**: 카메라가 선택한 오브젝트를 계속 바라봅니다. 움직이는 대상도 따라갑니다.
- **부모 붙이기·포즈**: 오브젝트를 다른 오브젝트에 붙여 함께 움직이게 할 수 있습니다. 인물·악기 등은 기본 포즈와 샷별 포즈를 고를 수 있고, 샷별로 숨길 수도 있습니다.
- **노래 싱크**: 음원을 불러와 BPM, 다운비트, 구간 마커를 넣으면 애니매틱이 음악과 같은 시계로 재생됩니다. 곡 전체 타임라인과 WebM 녹화 오디오도 지원합니다. 음원은 브라우저(IndexedDB)에만 저장됩니다.
- **참조 이미지**: 샷마다 키컷 이미지를 넣고 샷 카메라 위에 반투명으로 겹쳐 볼 수 있습니다(`R`).
- **샷별 라이팅**: 프로젝트 기본 라이팅 외에 샷마다 프리셋을 따로 지정할 수 있습니다(회상 호박색, 구름 틈 햇빛, 연필 종이 톤 등).
- **씬**: 인물 마네킹(트래킹할 때 걷기 동작), 자동차, 박스, 기둥, 벽, 나무, 테이블, 바닥 마크, 바위판, 부유 파편, 풍선·반사 풍선, 구름층, 균열 지면, 메트로놈, 드럼, 키보드, 마이크가 있고 라이팅 프리셋은 주간, 골든아워, 흐림, 야간, 실내입니다.
- **내보내기**
  - PNG 스틸
  - 영상(MP4·MOV, H.264): 현재 샷 또는 전체 애니매틱을 프레임 단위로 렌더링해 1080p로 인코딩합니다. 음원을 불러왔다면 AAC로 함께 들어갑니다. 최신 Chrome·Edge·Safari가 필요합니다(WebCodecs).
  - `.glb`: 씬과 샷별 카메라, 샷별 애니메이션 클립. Blender 등에서 불러올 수 있습니다.
  - 샷리스트와 영어 AI 영상 프롬프트(.md, 클립보드에도 복사)
  - 프로젝트 JSON(다시 열 수 있음, 브라우저에 자동 저장)

- **프롬프트 가이드 탭** (`guide.html`): 특정 프로젝트와 무관하게 쓸 수 있는 프롬프트 원칙 27개를 입력 설정, 문장 설계, 카메라 어휘, 글자, 운영 5개 그룹으로 정리했습니다. 항목별·전체 복사와 "신규만 보기" 필터가 있습니다.
- **프롬프트 게이지 탭** (`filter.html`): 범용 프롬프트를 고르고 게이지·옵션으로 조절합니다. 프롬프트 종류는 두 가지입니다.
  - **자막 지우기**: 영상에 박힌 자막을 지우는 프롬프트입니다. 자막 위치(하단·상단·상단+하단)와 배경 바 유무를 고르면 문장이 맞춰 바뀝니다.
  - **노스탤지어 필터**: 노스탤지어(추억) 필터 프롬프트의 강도를 게이지로 조절하면 영어 프롬프트가 자동으로 바뀝니다. 전체 체감 강도, 빛 번짐, 소프트 블러·비네트, 색 바램, 필름 그레인, 따뜻함을 단계별로 고르고(효과별로 끌 수도 있음), 이미지 참조 이름과 글씨 보호 문장 포함 여부를 정할 수 있습니다. 기본값에서 바뀐 부분은 노란색으로 표시하고, 서로 충돌하는 설정은 경고로 알려 줍니다. 모든 게이지가 기본값이면 원본 프롬프트와 글자까지 같습니다.

## 예제

상단 **예제 ▾** 메뉴에서 고를 수 있고, 링크 끝에 `#stadium`을 붙이면 바로 열립니다.

- **골목 대치 씬**: 대화 장면 5샷
- **야구장 도루 — 불릿타임 오빗**: 만원 관중이 들어찬 야간 야구장에서 시간이 멈춘 장면입니다. 2루에서 3루로 도루하는 주자만 고속 슬로모션(실제 속도의 약 1/8)으로 달리고, 카메라는 주자를 타깃으로 고정한 채 같은 거리(약 11m)를 유지하며 10초 동안 주자를 중심으로 한 방향으로 두 바퀴(720°) 돕니다(높이 2.45m, 24mm).
- **3루타 — 측면 트래킹 + 발 인서트** (`#triple`, 예전 `#steal`도 열림): 같은 야구장에서 3루타를 친 타자가 2루를 돌아 3루로 질주하는 장면을 2샷(총 4초)으로 나눴습니다. 중견수의 송구가 2루 뒤에서 기다리는 유격수(중계)에게 날아가고, 투수는 3루 뒤 파울 지역으로 백업하러 뜁니다. 카메라는 85mm로 주자와 나란히 측면 트래킹합니다.
  1. 측면 풀샷 트래킹(3초): 처음 1초는 프리즈(주자만 실제 속도의 약 1/8 슬로모션). 1초에 프리즈가 깨지며 0.3초 동안 정속으로 스피드 램프 — 송구가 유격수 글러브로 날아가고, 투수가 3루 백업 위치로 계속 달리고, 3루수가 베이스로 움직이고, 관중이 들썩이기 시작
  2. 인서트(1초, 정속): 지면 높이에서 발만 잡는 측면 트래킹. 주자가 3루 베이스 약 0.5m 앞에 다다를 때까지
- **대구 삼성 라이온즈 파크 — 만원 관중 (삼성 vs NC)** (`#lionspark`): 팔각형 펜스(좌우 99.5m, 중앙 122.5m), 파란 좌석, 내야 관중석 위 흰 지붕과 지붕 조명, 좌중간 대형 전광판이 있는 야간 구장입니다. 관중 약 1만 7천 명이 꽉 차 있고 몸 색으로 팀이 갈립니다. 3루 쪽과 외야는 삼성 라이온즈 팬(파랑·흰색), 1루 쪽 내야는 NC 다이노스 팬(남색·금색)입니다. 두 팀이 섞여 보이지 않도록 흰색은 삼성 팬에만 썼습니다. 2샷입니다.
  1. 항공 설정샷(8초, 24mm): 중견수 뒤쪽 높은 곳에서 홈플레이트 쪽으로 드론이 천천히 다가갑니다.
  2. 관중석 팬(6초, 35mm): 마운드 옆에서 삼성 쪽(3루)부터 홈 뒤를 지나 NC 쪽(1루)까지 팬합니다.
  - 아무 야구장 오브젝트나 인스펙터의 **구장** 메뉴에서 `일반 구장` / `대구 삼성 라이온즈 파크`를 바꿀 수 있습니다.
- **3루 슬라이딩 — 그라운드 로우앵글 슬로모션** (`#slide`): 같은 야구장에서 3루 베이스 옆 흙바닥에 고정한 10mm 초광각 카메라(더치 15°)로 10초 한 샷을 잡습니다. 주자가 발부터 슬라이딩해 들어오고, 3루수가 송구를 받아 베이스로 태그하며, 흙먼지가 슬로모션으로 솟아오릅니다.
