# Previz Studio (three.js)

샷 설명(텍스트)이나 샷 빌더로 카메라 무빙을 자동 생성하고, 애니매틱·glTF·AI 영상 프롬프트로 내보내는 브라우저용 프리비즈 도구입니다.

## 실행

빌드가 필요 없습니다. three.js는 `vendor/`에 포함되어 있어 오프라인에서도 동작합니다. ES 모듈을 쓰기 때문에 로컬 서버로 열어야 합니다.

```bash
cd previz
python3 -m http.server 8000
# http://localhost:8000
```

GitHub Pages 같은 정적 호스팅에 `previz/` 폴더를 그대로 올려도 됩니다.

## 기능

- **텍스트 → 샷 생성**: 한 줄에 한 샷씩 씁니다. 예: `배우A 클로즈업 로우앵글 천천히 달리인 85mm 4초 | 비 오는 골목에서 뒤돌아본다`
  - `|` 뒤에 쓴 내용은 액션 설명으로 들어갑니다.
  - 인식하는 항목: 샷 사이즈(ECU~EWS), 앵글(로우/하이/탑뷰/웜즈아이), 방향(정면/3/4/측면/뒷모습/오버숄더), 무브(달리 인/아웃, 트럭, 크레인, 오빗·360, 트래킹, 팬, 틸트, 휩팬, 달리줌, 드론), 속도, 핸드헬드, 더치, `NNmm`, `N초`, 씬 오브젝트 이름
- **샷 빌더**: 피사체, 사이즈, 앵글, 렌즈, 무브를 드롭다운으로 골라 생성합니다. 거리는 렌즈 초점거리, 센서 크기, 화면비로 계산해서 실제 프레이밍에 맞춥니다.
- **디렉터 뷰와 샷 카메라 뷰**: 카메라, 타깃, 오브젝트를 기즈모로 움직이면 현재 시간에 키가 생깁니다(자동 키). 타임라인에서 키를 드래그해 타이밍을 바꿀 수 있습니다.
- **XYZ 게이지**: 오브젝트 위치·회전과 카메라 위치·타깃을 슬라이더와 숫자 칸으로 조절합니다. 기즈모 색과 같은 색(X 빨강, Y 초록, Z 파랑)을 씁니다.
- **타깃 고정**: 카메라가 선택한 오브젝트를 계속 바라봅니다. 움직이는 대상도 따라갑니다.
- **부모 붙이기·포즈**: 오브젝트를 다른 오브젝트에 붙여 함께 움직이게 할 수 있습니다. 인물·악기 등은 기본 포즈와 샷별 포즈를 고를 수 있고, 샷별로 숨길 수도 있습니다.
- **노래 싱크**: 음원을 불러와 BPM, 다운비트, 구간 마커를 넣으면 애니매틱이 음악과 같은 시계로 재생됩니다. 곡 전체 타임라인과 WebM 녹화 오디오도 지원합니다. 음원은 브라우저(IndexedDB)에만 저장됩니다.
- **참조 이미지**: 샷마다 키컷 이미지를 넣고 샷 카메라 위에 반투명으로 겹쳐 볼 수 있습니다(`R`).
- **샷별 라이팅**: 프로젝트 기본 라이팅 외에 샷마다 프리셋을 따로 지정할 수 있습니다(회상 호박색, 구름 틈 햇빛, 연필 종이 톤 등).
- **씬**: 인물 마네킹(트래킹할 때 걷기 동작), 자동차, 박스, 기둥, 벽, 나무, 테이블, 바닥 마크, 바위판, 부유 파편, 풍선·반사 풍선, 구름층, 균열 지면, 메트로놈, 드럼, 키보드, 마이크가 있고 라이팅 프리셋은 주간, 골든아워, 흐림, 야간, 실내입니다.
- **내보내기**
  - PNG 스틸
  - WebM: 현재 샷 또는 전체 애니매틱을 실시간으로 녹화
  - `.glb`: 씬과 샷별 카메라, 샷별 애니메이션 클립. Blender 등에서 불러올 수 있습니다.
  - 샷리스트와 영어 AI 영상 프롬프트(.md, 클립보드에도 복사)
  - 프로젝트 JSON(다시 열 수 있음, 브라우저에 자동 저장)
