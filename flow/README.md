# 워크플로우 (Flow)

생성형 AI 이미지·영상 작업을 노드 캔버스로 정리하고, Higgsfield MCP로 실행하는 도구입니다. Video Skill의 다섯 번째 탭입니다.

프롬프트·레퍼런스·생성·가공을 노드로 놓고 선으로 이으면, 한 번 짜 둔 흐름을 샷마다 다시 쓸 수 있습니다.

## 실행

빌드가 필요 없습니다. 쓰는 방식이 세 가지입니다.

| 방식 | 준비 | 실제 생성 |
| --- | --- | --- |
| **데모** | 없음 (GitHub Pages·로컬 서버 어디서나) | 안 함. 자리 그림으로 흐름만 확인 |
| **MCP 연결** | 내 컴퓨터에서 브리지 서버 실행 + Higgsfield 로그인 | 캔버스에서 바로 생성 |
| **Claude 전달** | 없음 | 노드가 만든 요청을 Claude 채팅에 붙여넣고 결과 주소를 다시 붙여넣기 |

### MCP 연결 (브리지)

```bash
cd flow/server
npm install
npm start
# http://localhost:8787/flow/
```

1. 위 주소를 엽니다 (브리지가 사이트도 함께 띄웁니다).
2. 오른쪽 위 연결 버튼 → **MCP 연결** → Higgsfield 옆 **연결**.
3. 새 창에서 Higgsfield 계정으로 로그인·승인하면 자동으로 연결됩니다.
4. **모델 목록 새로 받기**를 누르면 계정에서 쓸 수 있는 최신 모델 목록으로 바뀝니다.

#### 버튼으로 켜기 (macOS)

매번 터미널을 열지 않으려면 한 번만 설치합니다.

```bash
cd flow/server
./install-mac.sh
```

그 뒤로는 연결 패널의 **켜기 · 확인** 버튼이 이 폴더를 최신 `main`으로 받아 온 뒤(직접 고친 파일이 없을 때만) 브리지를 켜고, 이어서 Higgsfield 연결과 모델 목록 받기까지 합니다(처음 한 번은 로그인 창이 뜹니다). 웹 페이지는 프로그램을 직접 실행할 수 없어서, 이 스크립트가 `flowbridge://start` 주소에 반응하는 작은 도우미 앱(`~/Applications/Flow Bridge.app`)을 만들어 둡니다. 처음 누를 때 Chrome이 "Flow Bridge 열기"를 물으면 허용하세요. 켜진 브리지는 패널의 **끄기**로 끕니다. 이 설치는 한 번이면 됩니다. 이후 업데이트(브리지를 켜는 방식이 바뀌는 것 포함)는 버튼을 누를 때 자동으로 받아 옵니다. 저장소 폴더를 옮기거나 Node.js를 다른 위치에 다시 설치했을 때만 다시 설치하고, 지울 때는 `./install-mac.sh --uninstall`입니다. 설치할 때 이 저장소의 GitHub Pages 주소(`https://<소유자>.github.io`)가 브리지를 쓸 수 있는 페이지로 함께 등록됩니다.

- 브리지는 내 컴퓨터(127.0.0.1)에서만 열리고, 로그인 정보는 `~/.flow-bridge/state.json`(본인만 읽기)에 저장됩니다.
- GitHub Pages에 올린 페이지에서 내 브리지를 쓰려면 브리지를 켤 때 그 주소를 허용합니다: `FLOW_ALLOWED_ORIGINS=https://이름.github.io npm start`. Safari는 https 페이지에서 `http://localhost` 호출을 막으므로 Chrome·Edge를 쓰거나 `http://localhost:8787/flow/`로 여세요.
- 다른 원격 MCP 서버(Streamable HTTP)도 연결 패널에서 추가할 수 있고, 그 도구는 **MCP 도구** 노드에서 골라 실행합니다. 입력 칸은 도구의 스키마로 자동으로 만들어집니다.
- 크레딧 없이 브리지 경로를 시험하려면 `node test/mock-mcp.mjs`로 가짜 서버를 띄워 `http://localhost:8799/mcp`를 추가하고, 연결 패널의 "이미지·영상 생성에 쓸 서버"에서 고릅니다. `npm test`는 이 가짜 서버로 브리지를 자동 점검합니다.

## 노드

| 노드 | 하는 일 |
| --- | --- |
| 텍스트 | 프롬프트, 캐릭터 설명, 공통 화풍 문장. "AI에게 시킬 내용"을 쓰고 **AI로 쓰기**를 누르면 Claude가 프롬프트를 써서 결과 칸에 넣고, 그 글이 다음 노드로 넘어감. 왼쪽 포트에 다른 텍스트를 연결하면 참고해서 씀 |
| 프롬프트 조합 | 여러 텍스트를 이어 붙이거나 `{1}` `{2}` 틀에 끼움 |
| 미디어 불러오기 | 레퍼런스 이미지·영상·오디오 (파일 또는 주소) |
| 이미지 생성 | 모델·화면비·해상도·변형 수. 레퍼런스 이미지 여러 장 연결 |
| 영상 생성 | 시작/끝 이미지, 레퍼런스 이미지·영상·오디오. 입력 포트는 고른 모델이 받는 것만 나옴 |
| 이미지 업스케일 | 2K·4K |
| 피드백 | 마음에 안 드는 결과(이미지·영상)를 연결하고 **피드백 받기**를 누르면 Claude가 결과를 직접 보고 원인 진단과 수정 프롬프트를 씀. 영상은 처음·중간·끝 프레임을 봄. 수정 프롬프트는 다음 노드로 넘어가고, `이 프롬프트로 다시 생성할 노드 만들기`로 원래 노드를 복사해 바로 이어 갈 수 있음 |
| 프레임 추출 | 영상의 마지막(또는 첫·지정) 프레임 → 다음 샷의 시작 이미지 |
| 샷 보드 | 결과를 샷 순서로 모아 보고 샷리스트(.md) 복사 |
| 메모 | 캔버스 메모 |
| MCP 도구 | 연결된 MCP 서버의 아무 도구나 실행 |

**AI로 쓰기**는 브리지가 켜져 있고 그 컴퓨터에 Claude Code(`claude` 명령)가 있으면 내 Claude 구독으로 바로 씁니다. 없으면 요청문을 Claude 채팅에 붙여넣고 답을 다시 붙여넣는 창이 뜹니다.

모델은 버튼을 눌러 고릅니다. 회사별 탭이 있고, 고르거나 실행한 모델은 **최근** 탭과 전체 목록 맨 위에 올라옵니다. 화면비의 **자동**은 모델에 자동 설정이 있으면 그것을, 없으면 모델 기본값을 씁니다. 영상 모드의 **텍스트만 (t2v)** 은 레퍼런스 없이 프롬프트만으로 만드는 방식이고, 이미지·영상을 연결하면 **레퍼런스 사용**으로 자동으로 바뀝니다. 드래프트는 480p 시안이라 다른 해상도를 고르면 꺼집니다.

**레퍼런스 태그**: 프롬프트에 `@Image 1`, `@Video 1`, `@Audio 1`처럼 쓰면 그 번호의 레퍼런스를 가리킵니다(`@image1`, `@이미지 1`도 됨). 번호는 레퍼런스 포트에 연결된 순서(위→아래)이고, 생성 노드의 프롬프트 아래에 번호와 출처가 칩으로 표시됩니다. 칩을 누르면 프롬프트에 태그가 들어갑니다. 연결된 텍스트 노드에 쓴 태그도 같이 처리되고, 보낼 때 Higgsfield가 읽는 표기(`@[Image 1](image_1)`)로 바뀝니다. 없는 번호를 쓰면 생성 전에 알려 줍니다. **AI로 쓰기**에도 그 텍스트가 이어지는 생성 노드의 레퍼런스 목록이 함께 넘어가서, 지시에 쓴 태그는 그대로 남고 태그 없이 이름(예: 캐릭터 시트)만 써도 알맞은 태그가 들어갑니다. 지시에 쓴 태그가 결과에서 빠지면 알려 줍니다. 시작·끝 이미지는 태그 번호에 들어가지 않습니다.

MCP 연결 상태에서는 이미지·영상 생성 노드 아래에 **예상 크레딧**이 표시됩니다(서버에 비용만 물어보며 생성은 하지 않음).

포트 색: 노랑 텍스트 · 파랑 이미지 · 빨강 영상 · 초록 오디오 · 보라 모든 값. 맞지 않는 종류끼리는 연결되지 않고, 순환 연결도 막습니다.

## 실행 규칙

크레딧이 드는 생성 노드는 **명시적으로 시킬 때만** 다시 돕니다.

- **노드의 ▶**: 그 노드만 새로 생성합니다. 위쪽 생성 노드는 결과가 있으면 그대로 쓰고, 없을 때만 함께 실행합니다.
- **여기부터 아래로 실행 / 전체 실행**: 결과가 없거나 설정·입력이 바뀐(`설정 바뀜` 표시) 생성 노드만 실행합니다. 생성 노드가 2개 이상이면 개수와 예상 크레딧을 먼저 보여 줍니다.
- **결과 잠금**: 마음에 든 결과를 잠그면 어떤 실행에서도 다시 생성하지 않습니다.
- 노드 테두리: 생성 중이거나 AI가 글을 쓰는 중이면 **노랑**, 끝나면 **초록**입니다. 설정이나 입력이 바뀌어 결과가 옛것이 되면 초록이 꺼지고 `설정 바뀜`이 표시됩니다.
- 결과 이미지·영상을 누르면 크게 보이고, 옆에 그 결과를 만든 모델·설정, **첨부한 레퍼런스**(태그 번호와 함께), **실제로 보낸 프롬프트**(연결된 텍스트와 태그가 합쳐진 최종본)가 나옵니다. 생성 전에는 노드 메뉴의 `보낼 요청 미리 보기`에서 같은 내용을 확인합니다. 레퍼런스 그림을 누르면 그 레퍼런스가 크게 열리고(오디오 레퍼런스는 재생기가 열려 바로 재생됨), `← 돌아가기`(또는 Esc)로 원래 창으로 돌아옵니다.
- 변형을 여러 장 만들면 테두리가 켜진 한 장이 다음 노드로 넘어갑니다. 다른 장을 누르면 바뀝니다.
- 생성할 때마다 결과에 **v1, v2, …** 번호가 붙고 노드 위쪽에 나란히 남습니다(12개까지). 번호를 누르면 그 버전이 다음 노드로 넘어가는 결과가 됩니다. 번호에 마우스를 올리면 모델과 시각이 보입니다.
- **드래프트 완성**: 드래프트(480p 시안)로 만든 영상 아래에 `1080p로 완성`, `4K로 완성` 버튼이 나옵니다. 업스케일이 아니라 Higgsfield의 Generate in 1080p/4K와 같은 방식으로, 그 드래프트를 고른 해상도로 다시 생성해 새 버전으로 넣습니다. 드래프트는 만든 지 7일 안에 완성할 수 있습니다.
- 앞 노드가 실패하면 뒤 노드는 건너뛰고, 상관없는 가지는 계속 실행합니다.

## 조작

- 빈 곳 더블클릭·우클릭·`A`: 노드 추가(이름으로 찾기)
- 포트에서 끌어 빈 곳에 놓기: 이어 붙일 수 있는 노드만 골라서 추가·연결
- 결과 이미지·영상을 캔버스 빈 곳으로 끌어내면 그 결과를 담은 **미디어 불러오기** 노드가 생깁니다(이름은 `노드 이름 v번호`). 다른 생성 노드의 레퍼런스로 바로 연결할 수 있고, 서버에 이미 있는 결과라 다시 올리지 않습니다. 컴퓨터의 이미지·영상·오디오 파일을 캔버스에 끌어다 놓아도 같은 노드가 만들어집니다.
- 연결선 가운데 더블클릭(또는 클릭 → `Delete`): 연결 끊기 / 연결된 입력 포트를 끌면 선을 떼어 옮김
- 선을 끌 때 가까운 포트에 달라붙음(스냅). 노드 몸통에 놓아도 맞는 첫 포트에 연결
- 빈 곳 끌기: 이동 · 휠: 확대/축소 · `Shift`+끌기: 여러 개 선택 · `F`: 전체 보기
- `Ctrl+Enter` 선택 노드 실행 · `Ctrl+D` 복제 · `Ctrl+C/V` · `Ctrl+Z` / `Ctrl+Shift+Z` · `Ctrl+S` 파일 저장
- 노드 제목 더블클릭: 이름 바꾸기(예: 샷 1)
- 자동 정렬: 왼쪽 아래의 `정렬`(또는 `L`). 연결 순서대로 왼쪽에서 오른쪽 열로 나누고, 열 안에서는 실제 높이에 맞춰 겹치지 않게 쌓습니다. 노드들의 위아래 순서는 그대로 유지하므로 프롬프트가 합쳐지는 순서와 레퍼런스 번호(`@Image 1`, `2`…)가 바뀌지 않습니다. 연결이 없는 노드(메모 등)는 아래쪽 한 줄에 놓입니다. 2개 이상 선택하면 그 노드들만 정렬하고, `Ctrl+Z`로 되돌립니다.
- 노드 접기: 제목 왼쪽의 `▾`(또는 노드 메뉴, `H`)를 누르면 모델·프롬프트 설정이 숨고 제목과 결과만 남습니다. 연결된 포트는 남아 선이 유지되고, 그림이 없는 노드는 글 앞부분이 보입니다. 여러 개를 선택하고 누르면 함께 접히고, 아무것도 선택하지 않고 `H`를 누르면 전체가 접히거나 펼쳐집니다.
- 겹친 노드의 위아래 순서: 노드 메뉴(⋯ 또는 우클릭)의 `맨 위로 / 한 칸 위로 / 한 칸 아래로 / 맨 아래로`, 또는 `]` `[` (한 칸), `Shift+]` `Shift+[` (맨 위·맨 아래). 한 칸은 겹쳐 있는 가장 가까운 노드를 하나 넘어갑니다.

워크플로우는 작업하는 동안 자동으로 저장되고, 다시 열면 마지막에 하던 워크플로우가 그대로 나옵니다. `파일 → 내 워크플로우…`에서 여러 개를 바꿔 열고 복제·삭제합니다. 보관 위치는 이 브라우저이고, 브리지가 켜져 있으면 내 컴퓨터의 `~/.flow-bridge/workflows`에도 함께 저장되어 공개 주소와 `localhost` 주소에서 같은 목록이 보입니다. `파일로 내보내기`로 `.flow.json`을 내려받아 다른 곳에서 가져올 수도 있습니다. 직접 넣은 파일과 추출한 프레임은 이 브라우저(IndexedDB)에만 있고 `.flow.json`에는 들어가지 않습니다.

## 템플릿

주소 끝에 `#i2v`, `#character`, `#chain`, `#compare`를 붙이면 바로 열립니다.

- **시작 이미지 → 영상**: 스틸을 만들고 그 스틸로 영상 생성
- **캐릭터 레퍼런스 멀티샷**: 캐릭터 시트 한 장을 세 샷의 레퍼런스로
- **샷 이어 붙이기**: 앞 샷의 마지막 프레임을 다음 샷의 시작 이미지로
- **모델 비교**: 같은 시작 이미지·프롬프트를 영상 모델 세 개에

## 설계 근거 (2026-11 조사)

Higgsfield Canvas, 뉴테이크, Freepik Spaces, Flora, Krea Nodes, Weavy(Figma Weave), ComfyUI, Runway Workflows를 조사해 공통 패턴과 불만을 반영했습니다. 조사 환경에서 각 제품의 공식 페이지를 직접 열 수 없어 검색 요약에 의존했으므로, 세부 UI는 추정이 섞여 있습니다.

| 조사에서 본 것 | 여기에 넣은 것 |
| --- | --- |
| 종류별 포트·색 구분, 맞는 것끼리만 연결 (Krea, Weavy, Runway) | 포트 5종 색 구분, 끌 때 연결 가능한 포트만 강조 |
| 노드 실행 / 전체 실행 / 아래로 실행 (Freepik) | 세 가지 실행 + 선택 실행 |
| 그래프 구성은 무료, 생성할 때만 크레딧 (Higgsfield) | 데모 모드, 실행 전 개수·예상 크레딧 확인 |
| 출력 잠금, 실행 중 목록·취소 (Runway) | 결과 잠금, 실행 표시줄과 노드별 중단 |
| 영상 생성 전에 프롬프트를 검수하지 않으면 크레딧 낭비 (Flora 사용자) | 노드 메뉴의 `보낼 요청 미리 보기`(합쳐진 프롬프트·설정·레퍼런스), `설정 바뀜` 표시, 변한 노드만 재실행 |
| 캐릭터 시트를 영상 노드에 연결해 얼굴 유지 (뉴테이크) | 캐릭터 레퍼런스 템플릿, 한 레퍼런스를 여러 샷에 연결 |
| 마지막 프레임을 다음 생성에 연결 (Higgsfield Extend 패턴) | 프레임 추출 노드, 샷 이어 붙이기 템플릿 |
| 우클릭으로 노드 검색 추가, 스티키 노트 (Weavy, Krea) | 검색 팔레트, 메모 노드 |
| 학습 곡선·모델 선택 혼란 (ComfyUI, Weavy 리뷰) | 노드 11종으로 제한, 모델이 받는 입력만 포트로 표시, 회사별 탭과 최근 사용 모델 |

기술 선택: 이 저장소의 다른 도구와 같게 빌드 없는 정적 페이지(ES 모듈)로 만들었습니다. 원격 MCP 서버는 OAuth 로그인이 필요하고 브라우저에서 직접 부르도록 열려 있다는 근거를 찾지 못해, 연결은 로컬 Node.js 브리지(공식 MCP SDK)가 맡습니다.

## 알려진 한계

- **Higgsfield 실제 로그인·생성은 아직 확인하지 못했습니다.** 개발 환경에서 `mcp.higgsfield.ai`가 막혀 있어, 브리지는 가짜 MCP 서버로만 끝까지 시험했습니다. Higgsfield 도구의 인자 형식, `get_cost`·`jobs_wait`·`media_upload` 응답 형식은 실제 서버에서 확인했지만, **완료된 작업의 결과 주소가 담기는 칸 이름**은 확인하지 못해 응답 안의 주소를 찾아 쓰도록 만들었습니다.
- Higgsfield MCP가 앱 자동 등록(OAuth 동적 클라이언트 등록)을 받는지 확인하지 못했습니다. 받지 않으면 연결 단계에서 그 내용의 오류가 표시되고, 그때는 **Claude 전달** 방식을 쓰면 됩니다.
- 데모 모드의 영상은 움직이지 않는 자리 그림입니다.
- 실시간 협업, 노드 그룹, 자연어로 그래프 만들기는 없습니다. 터치 화면에서는 한 손가락 이동과 확대·축소 버튼만 됩니다.
